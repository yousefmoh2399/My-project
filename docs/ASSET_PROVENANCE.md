# ASSET PROVENANCE — KING WORLD WAR

This document records the provenance, licensing, and authorship of all assets used in KING WORLD WAR.

## 1. POLICY & MANDATE

As established in `AGENTS.md` and the project Work Order:
- **Zero Copyright Infringement:** Never use assets, maps, models, audio, or code from *Warpath* or any copyrighted commercial title.
- **Approval Gate:** Any third-party or paid package must be approved by the project owner before addition.
- **Original Identity:** Maintain a distinct military-modern aesthetic using the official project palette.
